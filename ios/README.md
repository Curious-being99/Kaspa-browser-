# Kazium for iOS (Real Apple WebKit Engine)

This directory contains the native iOS companion for **Kazium** powered by **Kazview WebKit** (`WKWebView`).

## Features
- **Real Apple WebKit (`WKWebView`)**: Runs genuine Apple WebKit on iOS devices.
- **Desktop Mode Viewport**: Toggles desktop content mode (`.desktop` / `.mobile`) and custom Safari/WebKit user agent.
- **Privacy Controls**: Isolated cookie & data stores with script injection guards.
- **Seamless Navigation**: Integrated top-bar with Kaspa address & web navigation.

## How to Build & Run on iPhone
1. Open this directory or import the files into an Xcode project (SwiftUI App target for iOS 16+).
2. Set your iOS Development Team in Xcode under **Signing & Capabilities**.
3. Select your iPhone device or an iPhone Simulator (e.g., iPhone 15/16 Pro).
4. Press **Cmd + R** to run.
